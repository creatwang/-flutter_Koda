# 国际化发版回归清单

> 在常规功能回归基础上，增加语言维度。建议每轮发版至少跑 **中文 + 英文** 各一遍。  
> 详细步骤见 [i18n_test_plan.md](./i18n_test_plan.md)。

---

## A. 发版前检查（开发）

- [ ] 修改过 `lib/l10n/*.arb` 后已执行 `flutter gen-l10n`
- [ ] `app_en.arb` 与 `app_zh.arb` 键集合一致（无单侧缺键）
- [ ] `dart analyze lib` 无 error
- [ ] 未向 `lib/features|shared|core|app` 新增用户可见字面量（接口 message 除外）
- [ ] 已阅读 [i18n_migration_audit.md](./i18n_migration_audit.md) 第 5 节「不纳入范围」

---

## B. 语言与持久化（P0）

- [ ] Settings 切换 **中文** → 主要 Tab 文案为中文
- [ ] Settings 切换 **English** → 主要 Tab 文案为英文
- [ ] 强杀进程重启后语言保持
- [ ] 「跟随系统」在系统 zh/en 下表现正确

---

## C. 核心业务流程（P0）

### 登录与会话

- [ ] 登录成功进入首页
- [ ] 登录失败提示可读（当前语言或接口原文）
- [ ] 会话过期弹窗 → 确认后回登录页

### 商品 → 购物车

- [ ] 浏览商品列表 → 进详情 → 加购成功提示
- [ ] 购物车可见新行 → 改数量 / 改规格
- [ ] 扫码加购（已登录）流程完成

### 预订单 / 下单

- [ ] 预订单列表加载
- [ ] Checkout 成功提示为当前语言

### 个人中心

- [ ] 修改资料/密码（若有变更）成功提示
- [ ] 切换站点成功
- [ ] 业务员：客户列表打开；代客登录 / 切回主账号（若适用）

---

## D. 弹窗与全局提示（P1）

- [ ] 确认弹窗：取消 / 确定按钮为当前语言（`commonCancel` / `commonConfirm`）
- [ ] 清空购物车确认流：标题、正文、成功/失败 SnackBar
- [ ] 未下单商品拦截弹窗（若业务可触发）
- [ ] 顶部 YnToast：错误 / 警告 / 成功样式正常，默认文案非写死 `error!`

---

## E. 错误与边界（P1）

- [ ] 列表页断网：错误文案 + 重试
- [ ] 接口带 `message` 的失败：展示服务端文案（不因切语言被替换）
- [ ] 接口无 `message` 的失败：展示当前语言 fallback（非裸 `DioException` 英文堆栈）

---

## F. 平台与布局（P2）

- [ ] 手机竖屏：长英文不换行溢出（Profile 设置、购物车行）
- [ ] 平板 / 宽屏：商品详情、购物车分栏正常
- [ ] Debug：Secure Storage 调试页文案随语言（仅 Debug 包）

---

## G. 已知排除（回归不测）

- [ ] `lib/examples/**` 演示页（不要求 i18n）
- [ ] `login_page` 内已注释的 Terms / Copyright 区块
- [ ] 后端返回的商品名、分类名等业务数据
