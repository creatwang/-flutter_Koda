# 代码变更收尾（强制）

> 来源：`storev2_front` 工作流 `simplification` + `verification`。  
> **触发**：任何代码变更完成后、声称完成之前。  
> **强制性**：不得跳过。

## 铁律

```text
实现完成
  → 代码简化（强制）
  → 完成验证（新鲜证据）
  → 才能声称完成 / 进入下一任务 / 提交或开 PR
```

没有可安全简化的内容时：记录「已检查、无可简化」，保持代码不变。  
没有本轮新鲜验证命令输出：不得声称通过、完成、已修复。

## 一、代码简化（强制）

在不改变已确认行为、公开接口、错误处理语义或性能目标的前提下，降低**本次变更**触及代码的复杂度。不以「清理」扩大为无关重构。

### 允许

- 早返回缩短嵌套
- 合并本次范围内的重复逻辑
- 删除无业务价值的中间变量、包装层或抽象
- 改善本次新增/修改代码的命名、结构与项目规范一致性
- 将难读复杂条件拆为清晰可测分支
- 清理**本次改动产生的**未使用 import / 变量 / 死代码

### 禁止

- 改变已确认业务功能或用户可见行为
- 改变对外 API、类型契约或公开接口
- 改变错误处理、降级与异常传播语义
- 牺牲已确认性能目标
- 重构未在本次变更范围内的历史代码
- 引入新依赖、运行时机制或额外功能

### 步骤

1. **确认范围**：按需求 / plan / diff 列出本次触及文件与关键逻辑
2. **对照行为简化**：以测试、规格、调用方契约为边界，做最小行为等价改写
3. **保护覆盖**：保留现有覆盖；若简化触及无测试行为，补最小锁定测试（有测则补）
4. **重新验证**：进入下一节，用命令确认无回归
5. **同步说明**：若简化改变模块结构/关键接口/可维护性约束，同步相关文档

## 二、完成验证（门控）

```text
没有新鲜验证证据，就不声称完成
```

本轮消息中未运行验证命令 → 不能声称它通过。

### 门控流程

1. **确定**：哪条命令能证明该声明？
2. **运行**：执行完整命令（新鲜、完整）
3. **阅读**：完整输出、退出码、失败数
4. **验证**：输出是否支持声明？
   - 否 → 报告实际状态与证据
   - 是 → 带证据再声明
5. **然后才能**声称完成

跳过任一步 = 未验证，不是完成。

### 本项目默认验证命令

按变更影响面选择，**至少跑与声明匹配的项**：

| 场景 | 命令 | 通过标准 |
| --- | --- | --- |
| 改了 Dart 代码 | `dart analyze lib` 或 `flutter analyze` | 无 error（相对本次引入） |
| 有/改了测试 | `flutter test`（可缩小到相关路径） | 0 failures |
| 改了 Freezed / JSON / FlutterGen 注解或资源 | `dart run build_runner build --delete-conflicting-outputs` | exit 0，生成物一致 |
| 声称 bug 已修 | 能复现原症状的测试或等价检查 | 通过 |
| IDE 诊断 | 对本次编辑文件读 lints | 无新增相关 error |

不充分：「应该过了」、上一轮结果、只 lint 就声称构建/运行时 OK、信任子代理「成功」报告。

### 常见声明 ↔ 证据

| 声明 | 需要 | 不充分 |
| --- | --- | --- |
| 分析通过 | analyze 输出无 error | 「看起来没问题」 |
| 测试通过 | test 输出 0 失败 | 之前的运行结果 |
| Bug 已修复 | 原始症状验证通过 | 代码改了就假设修好 |
| 需求已满足 | 逐项对照清单 | 测试通过 ≠ 需求满足 |
| 子代理完成 | 检查 VCS diff + 自行验证 | 子代理口头成功 |

## 三、危险信号 — 立刻停下

- 使用「应该 / 大概 / 看起来 / 似乎」描述结果
- 验证前表达满意（「完成了」「没问题」）
- 准备提交 / 推送 / PR 但未跑验证
- 依赖部分验证或信任子代理成功报告
- 想「这次算了」

## 四、收尾检查清单

每次改完代码后复制并勾选：

```text
收尾进度：
- [ ] 已按 diff 做局部行为等价简化（或记录无可简化）
- [ ] 未扩大范围到无关重构
- [ ] 已运行与声明匹配的验证命令（本轮新鲜输出）
- [ ] 已阅读完整输出与退出码
- [ ] 仅在证据支持时声称完成
```

## 底线

先简化（或确认无可简化），再跑命令读输出，**然后才能**声称结果。不可商量。
